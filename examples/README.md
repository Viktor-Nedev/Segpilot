# Sample outputs

Everything here is real output from this repo, committed so judges can evaluate
without running anything. All of it regenerates with the commands shown.

## `reports/`

- **`replay_report.md`** — the headline result. Offline replay of 7 recorded
  sessions (3 drift campaigns + 4 single-bug controls) under all five compression
  arms, split by population. Leads with the honest verdict: intent/kind routing
  does not reliably beat Paritok's stock defaults.
- **`pareto.svg`** — spend (tokens) vs must-keep retention, per arm. Must-keep is
  the axis on which the arms actually differ; task-relevant retention saturates.

Regenerate:

```bash
python -m segpilot.replay.report --out examples/reports/
```

## `traces/`

- **`campaign_1_segpilot.trace.jsonl`** — an authentic Paritok compression trace
  (the format `paritok/pipelines/compress.py` writes), generated by running three
  segments of a drift session through Paritok's `CompressionPipeline`.
- **`campaign_1_segpilot.md`** — the same trace rendered by `segpilot.viewtrace`,
  the before/after viewer that Paritok's own code references but does not ship
  (finding #7). Note segment 1: the compressor kept the failing assertions
  (`2.68` vs `2.67`, `193.05` vs `214.50`) and dropped the verbose docstrings —
  compression working as intended.

View any trace:

```bash
python -m segpilot.viewtrace <trace.jsonl>            # readable before/after
python -m segpilot.viewtrace <trace.jsonl> --markdown # Markdown
```

## `probe_output.txt`

Recorded output of `python -m segpilot.probe --all` — the lever sweep that
establishes which Paritok parameters the hosted GPU actually honours: `query`
and `kind` yes, `level` and `target_ratio` no (the latter accepts `"BANANA"`
with HTTP 200). This is the measurement the whole project is built on.

```bash
python -m segpilot.probe --all
```

## `sessions/`

The seven neutral reference trajectories (`*__raw.jsonl`) the replay sweeps over,
recorded with compression off so the agent chose its path on full context. These
are the inputs to `replay_report.md`; committing them lets you reproduce the
exact numbers:

```bash
python -m segpilot.replay.harness --all --suffix __raw \
  --arms stock,kind_only,intent_only,segpilot,segpilot+guard
```
