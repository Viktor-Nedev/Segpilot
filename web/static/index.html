SEGPILOT // live measurement · built with Paritok

We measured whether routing Paritok's compression per‑segment helps. It mostly doesn't.

Most "we optimized X" projects ship the idea and a flattering number. We shipped the idea, then measured it honestly across real agent sessions and reported that it does not reliably beat Paritok's stock defaults. Below: the live numbers, a real compression demo you can run on your own text, and nine reproducible findings about Paritok's hosted API.

    The reference sessions are committed, so the replay reproduces the exact figures above without recording anything new.
    
    
    # which Paritok parameters actually work
python -m segpilot.probe --all

# the arms, replayed over the committed sessions
python -m segpilot.replay.harness --all --suffix __raw \
  --arms stock,kind_only,intent_only,segpilot,segpilot+guard

# regenerate the report + this site's data
python -m segpilot.replay.report --out examples/reports/ --json
